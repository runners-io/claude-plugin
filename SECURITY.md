# Security

Please report a vulnerability in this plugin privately, not in a public issue: to **security@runners.io**, or through
GitHub's [private vulnerability reporting](https://github.com/runners-io/claude-plugin/security/advisories/new). Include what you
found, how to reproduce it, and the version (`.claude-plugin/plugin.json`).

We will acknowledge your report within three working days and tell you what we will do about it. Please give us a
reasonable time to fix it before you publish anything.

## Supported versions

Only the newest release is supported: a fix is published as a new release, never as a change to an old one, and release
tags are not moved. The [releases page](https://github.com/runners-io/claude-plugin/releases) shows the newest, and
[CHANGELOG.md](CHANGELOG.md) says what each one changed.

## What the plugin does

What this plugin does with your GitHub token, and what it runs on your machine, is described under
[Security in the README](README.md#security).
